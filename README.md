## 📋 نظرة عامة

الموقع المتعدد المجالات هو منصة شاملة تقدم محتوى موثوق ومتميز في ثلاثة مجالات أساسية:

- **البرمجة والتقنية**: دروس وشروحات عملية حول لغات البرمجة، تطوير المواقع والتطبيقات، وأحدث التقنيات الناشئة
- **الطب والصحة**: مقالات صحية موثوقة، نصائح طبية عامة، ووصفات طبيعية وعلمية
- **الدين والروحانيات**: محتوى ديني موثوق يشمل تفسير القرآن الكريم، الفقه الإسلامي، والعلوم الشرعية

### ✨ المميزات

- 🎨 تصميم جذاب واحترافي متجاوب مع جميع الأجهزة
- 📱 متوافق مع الكمبيوتر والموبايل والتابليت
- 🔍 نظام بحث داخلي متكامل
- 🛠️ أدوات تفاعلية مفيدة (آلة حاسبة، عداد تسبيح، مؤشر كتلة الجسم)
- ⚡ سرعة تحميل عالية وتجربة مستخدم سلسة
- 🔒 تحسين محركات البحث (SEO) متكامل
- 🌙 دعم اللغة العربية بالكامل (RTL)
- 📦 جاهز للاستضافة على GitHub Pages

## 🚀 كيفية النشر على GitHub Pages

### الطريقة الأولى: باستخدام GitHub Actions (الطريقة الموصى بها)

1. **إنشاء مستودع جديد على GitHub**

   ```
   - انتقل إلى GitHub.com
   - انقر على زر "New repository"
   - اختر اسم للمستودع (مثلاً: multi-domain-website)
   - اختر "Public"
   - انقر على "Create repository"
   ```

2. **رفع الملفات إلى المستودع**

   ```bash
   # نسخ المستودع محلياً
   git clone https://github.com/your-username/multi-domain-website.git
   cd multi-domain-website

   # إضافة الملفات
   git add .

   # إنشاء commit
   git commit -m "إضافة الموقع المتعدد المجالات"

   # رفع الملفات إلى GitHub
   git push origin main
   ```

3. **تفعيل GitHub Pages**

   ```
   - انتقل إلى إعدادات المستودع (Settings)
   - انقر على "Pages" في القائمة الجانبية
   - تحت "Source"، اختر "GitHub Actions"
   - سيتم إنشاء ملف workflow تلقائياً
   ```

4. **الوصول إلى الموقع**

   ```
   بعد نشر الموقع، سيكون متاحاً على:
   https://your-username.github.io/multi-domain-website/
   ```

### الطريقة الثانية: النشر من الفرع main

1. **رفع الملفات كما في الخطوات أعلاه**

2. **تفعيل GitHub Pages من الفرع الرئيسي**

   ```
   - انتقل إلى إعدادات المستودع (Settings)
   - انقر على "Pages" في القائمة الجانبية
   - تحت "Source"، اختر "Deploy from a branch"
   - تحت "Branch"، اختر "main" و"/ (root)"
   - انقر على "Save"
   ```

## 🎨 التخصيص

### تغيير الألوان

لتغيير الألوان الرئيسية للموقع، عدّل المتغيرات في ملف `css/style.css`:

```css
:root {
    --primary-color: #4f46e5;    /* اللون الرئيسي */
    --secondary-color: #0ea5e9;  /* اللون الثانوي */
    --accent-color: #f59e0b;     /* لون التوكيد */
    /* ... باقي المتغيرات */
}
```

### إضافة صفحات جديدة

1. أنشئ ملف HTML جديد في مجلد `pages/`
2. استخدم أحد الصفحات الموجودة كقالب
3. أضف الرابط في قائمة التنقل في جميع الصفحات

### تعديل القائمة

لتعديل القائمة الرئيسية، ابحث عن الكود التالي في كل ملف HTML:

```html
<nav class="main-nav">
    <ul class="nav-list">
        <li><a href="index.html" class="nav-link">الرئيسية</a></li>
        <li><a href="pages/programming.html" class="nav-link">البرمجة والتقنية</a></li>
        <!-- أضف أو عدل الروابط هنا -->
    </ul>
</nav>
```
