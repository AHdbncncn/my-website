📌 مقدمة عن بايثون

بايثون هي لغة برمجة تفسيرية، كائنية التوجه، ومتعددة الاستخدامات. صممها جايدو فان روسم وأطلقها عام 1991. تتميز بتركيبة بسيطة وواضحة تجعلها مثالية للمبتدئين والمحترفين على حد سواء.

💡 مميزات لغة بايثون:
  • سهلة التعلم والقراءة
  • مكتبات ضخمة ومجتمع نشط
  • متعددة المنصات (تعمل على Windows, Mac, Linux)
  • مجانية ومفتوحة المصدر
  • تستخدم في مجالات متنوعة (ويب، ذكاء اصطناعي، ألعاب، وغيرها)

🏗️ هيكل HTML الأساسي

HTML (لغة ترميز النص الفائق) هي اللغة القياسية لإنشاء صفحات الويب. تصف HTML بنية صفحة الويب وتتكون من سلسلة من العناصر التي تخبر المتصفح كيفية عرض المحتوى.

<!DOCTYPE html>
<html lang="ar" dir="rtl">
<head>
  <meta charset="UTF-8">
  <title>عنوان الصفحة</title>
  <link rel="stylesheet" href="style.css">
</head>
<body>
  <header>
    <h1>مرحباً بالعالم!</h1>
  </header>
  <main>
    <p>هذه صفحتي الأولى على الويب</p>
  </main>
  <footer>
    <p>حقوق النشر محفوظة © 2024</p>
  </footer>
</body>
</html>

🎨 تنسيق CSS

CSS (أوراق الأنماط المتتالية) تسمح لك بإنشاء صفحات ويب جميلة وجذابة من خلال فصل المحتوى عن العرض.

💡 مزايا استخدام CSS:
  • فصل المحتوى عن التصميم
  • توفير الوقت والجهد
  • تحسين أداء الصفحات
  • التصميم المتجاوب للهواتف المحمولة
  • إعادة استخدام الأنماط

⚛️ ما هي React؟

React هي مكتبة JavaScript لبناء واجهات المستخدم (UI). تتيح لك إنشاء مكونات UI قابلة لإعادة الاستخدام ومعزولة. تقوم React بتحديث وتقديم المكونات الصحيحة عندما تتغير بياناتك.

💡 مميزات React:
  • مكونات قابلة لإعادة الاستخدام
  • DOM افتراضي لتحسين الأداء
  • منحنى تعلم معقول للمطورين الملمين بـ JavaScript

  • مجتمع ضخم ونشط
  • تستخدم من قبل شركات كبيرة مثل Facebook و Instagram

🏗️ المكونات في React

// مكون وظيفي (Functional Component)
import React from 'react';

function Welcome(props) {

// مكون مع State باستخدام Hooks
import React, { useState } from 'react';

function Counter() {
  const [count, setCount] = useState(0);

  return (
    <div>
      <h2>العداد: {count}</h2>
      <button onClick={() => setCount(count + 1)}>
        زيادة
      </button>
      <button onClick={() => setCount(count - 1)}>
        تقليل
      </button>
    </div>
  );
}

🔗 Props وState

📊 الفرق بين Props و State:
  • Props (الخاصيات): بيانات تمرر من مكون أب إلى مكون ابن - للقراءة فقط
  • State (الحالة): بيانات خاصة بالمكون - يمكن تغييرها من داخل المكون
// مكون يستخدم كلاً من Props و State
import React, { useState } from 'react';

function UserProfile(props) {
  const [isOnline, setIsOnline] = useState(false);

  const toggleStatus = () => {
    setIsOnline(!isOnline);
  };

  return (
    <div className="user-profile">
      <h2>{props.name}</h2>
      <p>العمر: {props.age}</p>
      <p>الحالة: {isOnline ? 'متصل' : 'غير متصل'}</p>
      <button onClick={toggleStatus}>
        تغيير الحالة
      </button>
    </div>
  );
}

// استخدام المكون
<UserProfile name="أحمد" age={25} />

🧠 ما هو الذكاء الاصطناعي؟

الذكاء الاصطناعي (AI) هو محاكاة الذكاء البشري في الآلات المبرمجة للتفكير والتعلم والتكيف. يتضمن الذكاء الاصطناعي عدة مجالات فرعية رئيسية.

💡 مجالات الذكاء الاصطناعي:
  • تعلم الآلة (Machine Learning): خوارزميات تتعلم من البيانات
  • التعلم العميق (Deep Learning): استخدام الشبكات العصبية
  • معالجة اللغات الطبيعية (NLP): فهم وتوليد النصوص
  • الرؤية الحاسوبية (Computer Vision): فهم الصور والفيديو
  • الروبوتات (Robotics): التحكم في الآلات الذكية

📊 أنواع تعلم الآلة

📋 التصنيفات الرئيسية:
  1. التعلم بالإشراف (Supervised Learning): النموذج يتعلم من بيانات مسماة (labeled data)
  2. التعلم بدون إشراف (Unsupervised Learning): النموذج يجد أنماط في بيانات غير مسماة
  3. التعلم التعزيزي (Reinforcement Learning): النموذج يتعلم من خلال المكافآت والعقوبات
# مثال على خوارزمية تعلم بالإشراف باستخدام Python و scikit-learn
from sklearn import datasets
from sklearn.model_selection import train_test_split
from sklearn.linear_model import LogisticRegression
from sklearn.metrics import accuracy_score

# تحميل مجموعة بيانات Iris
iris = datasets.load_iris()
X = iris.data
y = iris.target

# تقسيم البيانات إلى تدريب واختبار
X_train, X_test, y_train, y_test = train_test_split(
  X, y, test_size=0.3, random_state=42
)

# إنشاء وتدريب النموذج
model = LogisticRegression()
model.fit(X_train, y_train)

# التنبؤ والتقييم
predictions = model.predict(X_test)
accuracy = accuracy_score(y_test, predictions)

print(f"دقة النموذج: {accuracy:.2%}")

🏗️ الشبكات العصبية الاصطناعية

الشبكات العصبية الاصطناعية هي أنظمة تحاكي طريقة عمل الدماغ البشري في معالجة المعلومات.

# مثال على شبكة عصبية باستخدام TensorFlow و Keras
import tensorflow as tf
from tensorflow import keras

# تحميل بيانات MNIST (تصنيف الأرقام)
mnist = keras.datasets.mnist
(x_train, y_train), (x_test, y_test) = mnist.load_data()

# تطبيع البيانات
x_train, x_test = x_train / 255.0, x_test / 255.0

# بناء النموذج
model = keras.Sequential([
  keras.layers.Flatten(input_shape=(28, 28)),
  keras.layers.Dense(128, activation='relu'),
  keras.layers.Dropout(0.2),
  keras.layers.Dense(10, activation='softmax')
])

# تجميع النموذج
model.compile(optimizer='adam',
              loss='sparse_categorical_crossentropy',
              metrics=['accuracy'])

# تدريب النموذج
model.fit(x_train, y_train, epochs=5)

# تقييم النموذج
test_loss, test_acc = model.evaluate(x_test, y_test)
print(f'دقة الاختبار: {test_acc:.2%}')
